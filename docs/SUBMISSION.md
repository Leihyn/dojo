## One-line

Dojo ranks the 310,000 agents registered on BNB Chain under ERC-8004 by graded evidence — probes,
receipts and replay — instead of by what their registration file claims.

## Short description (~100 words)

BscScan says 310,000 agents are registered on BNB Smart Chain under ERC-8004. Open ten of them and
three have empty registration files, four point at a dead URL, and two are the same scaffold called
"studio-agent". The registry tells you an agent exists; it does not tell you whether it works.

Dojo does that work before the user arrives. It resolves every registration file, calls every
endpoint the agent advertises, reads reputation off the chain per tag and per author, and grades
what agents actually do — scoring each one on the claim it really makes, against a baseline it has
to beat. Four jobs, equal billing, evidence instead of a pitch.

## How it addresses the brief

**Land, find by category, understand, activate.** Home page gives the four required categories equal
weight. `/agents` filters by category, chain, protocol and whether the agent answers. Each detail
page shows registration warnings, timestamped endpoint probes anyone can re-run, live on-chain
reputation, and a graded score. Activation runs the agent and returns a receipt.

**Data quality beyond basic counts.** `/quality` reports how much of the registry survives contact:
registration files that resolve, endpoints that answer, and — new — which registry filters failed
during the build, so narrower coverage is disclosed rather than hidden. Names come from the live
agent card, not the registry, because eight testnet agents registered as "studio-agent" turned out
to be a health-factor agent, a grid agent and so on once their cards were read.

**Agent diversity.** The four required categories are surfaced with equal billing on the home page
and each has a dedicated view.

## The differentiator, stated plainly

Every marketplace can list agents. Dojo grades them, and the grade measures the claim the agent
actually makes rather than a generic return number:

| Agent | What it claims | Scored against | Result |
|---|---|---|---|
| Range Keeper | this position should be recentred | the range it rejected | **74/100** — 151 decisions, +41.9 pts, t=12.38 |
| Grid Planner | this ladder is worth running | the same budget held in BNB | **17/100** — 163 decisions, −0.45%, t=−6.17 |

The Grid Planner is ours and it scores 17. It lost to simply holding BNB across a week when BNB
rallied, because a grid sells into a rally. It ships as measured. A marketplace that only ever
surfaces flattering numbers is the thing this replaces.

Both numbers are labelled in the UI as replay-graded backtests, not live track records, and both
reproduce from one command.

## Partner tracks

**TermiX — Agent Advantage Report.** `docs/AGENT_ADVANTAGE_REPORT.md`, generated by running three
real tasks twice each against mainnet, one of them a risk/security task. Measured: wall time and
contract reads on both arms. Assumed and declared: human time per lookup. The finding worth reading
is that on the yield task the two arms disagreed by 69% — 2.80% APY against 1.66% — because the
Venus API rate and raw `supplyRatePerBlock` are different quantities and a block explorer does not
say which one you are holding.

**PancakeSwap.** Two of the four reference agents read PancakeSwap directly: the Grid Planner prices
BNB/USDT off the v2 pair and the v3 pool and cross-checks them against each other, and the Range
Keeper reads the v3 pool tick and proposes a recentred range snapped to the pool's tick spacing so
the mint does not revert.

**Altana — session keys.** Not implemented. `/api/activate` returns a 501 naming exactly what is
missing rather than pretending; see the status table in the README.

## What is not done, stated up front

- The four reference agents are **not yet registered** on the ERC-8004 testnet registry — that needs
  a funded testnet key. They serve valid A2A agent cards and answer live today.
- **x402 pay-per-call activation is not wired.** The route reports what is missing.
- Grading is a **backtest**, not a live track record, and the UI says so on every score.
- Only the two price-driven agents are replay-gradeable. The Health Sentinel and Yield Scout show
  "no graded runs yet" rather than a number invented to fill the column.

## Verify it yourself

```bash
git clone https://github.com/Leihyn/dojo && cd dojo
pnpm install
pnpm --filter @dojo/core test                      # 47 tests
pnpm --filter @dojo/core replay -- --bars 2000 --interval 5m --horizon 240 --width 2 --age-min 720 --root ../..
pnpm --filter @dojo/core advantage -- --root ../..
```

Or hit a live reference agent directly:

```bash
curl -X POST https://dojo-psi-eosin.vercel.app/api/ref/venus-health \
  -H 'content-type: application/json' -d '{}'
```
